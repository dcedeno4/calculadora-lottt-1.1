# 💼 Calculadora LOTTT - Multiempresa v1.1

**Calculadora de Beneficios y Prestaciones Sociales** según la Ley Orgánica del Trabajo, los Trabajadores y las Trabajadoras (LOTTT) de Venezuela.

## ✨ Características

### 🏢 **Sistema Multiempresa**
- Gestión de múltiples empresas/patronos
- Base de datos local integrada
- Búsqueda en tiempo real
- Asociación automática trabajador-empresa

### 💰 **Cálculos Completos**
- ✅ Vacaciones y Bono Vacacional
- ✅ Utilidades
- ✅ Prestaciones Sociales
- ✅ Intereses sobre Prestaciones (3 modos)
- ✅ Días adicionales por antigüedad
- ✅ Vacaciones fraccionadas

### 📊 **Exportación Profesional**
- Excel detallado con todos los cálculos
- PDF de recibo profesional
- Diálogos nativos para guardar archivos

### 🌐 **Multiplataforma**
- **Windows** - Aplicación de escritorio
- **Mac** - Aplicación de escritorio
- **Linux** - Aplicación de escritorio
- **Android** - PWA instalable
- **iOS** - PWA instalable

## 🚀 Instalación

### Para PC (Desarrollo)

```bash
# Instalar dependencias
npm install

# Ejecutar aplicación
npm start

# Empaquetar para distribución
npm run build
```

### Para Móviles (PWA)

1. Subir carpeta `app/` a un servidor web
2. Acceder desde el navegador móvil
3. "Agregar a pantalla de inicio"
4. ¡Funciona como app nativa!

## 📱 Características PWA

- ✅ Funciona offline
- ✅ Instalable como app nativa
- ✅ Base de datos local (IndexedDB)
- ✅ Actualizaciones automáticas
- ✅ Notificaciones push (opcional)

## 🔧 Tecnologías

- **Electron** - Aplicaciones de escritorio
- **SQLite** - Base de datos local (PC)
- **IndexedDB** - Base de datos local (móviles)
- **Service Workers** - Funcionalidad offline
- **PWA** - Progressive Web App

## 📋 Requisitos

- Node.js 14 o superior
- npm 6 o superior

## 🔒 Seguridad
